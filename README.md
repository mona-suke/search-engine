# 社内向けデータベース検索エンジン

社内のデータベースから情報を検索するためのエンジンです。  
PHPでデータベースと連携しており、検索機能を提供しています。

## 技術スタック

- PHP（サーバーサイドロジック）  
- HTML / JavaScript（画面表示・ユーザー操作）  
- MySQL（データベース、会社のサーバーに設置）

## 機能

- データベースからの検索機能（PHP関数で実装）  
- 検索結果の表示（HTML・JavaScriptで画面を構成）
- 検索したデータをexcelとしてダウンロード
- 複数品種・地域を選択して表示可能

## 注意点

- データベースとサーバーは会社内の環境で稼働しているため、外部環境では動作しません。  
- 現状コードベースで開発中のため、動作環境は限定的です。
